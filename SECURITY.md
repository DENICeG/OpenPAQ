# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in **{Project Name}**, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

Instead, contact the maintainers directly via email:

**security@denic.de**

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any suggested mitigations or fixes (optional)

We aim to acknowledge receipt within **5 business days** and will keep you informed as we work toward a resolution.

## Disclosure Policy

We follow coordinated disclosure:

1. You report the vulnerability privately.
2. We investigate and develop a fix.
3. We release the fix and publish a security advisory.
4. We credit you in the advisory unless you prefer to remain anonymous.

We aim to resolve critical vulnerabilities within **90 days** of receipt.

## Publication of Vulnerabilities

Discovered and resolved vulnerabilities are documented in:

- The [Changelog](./docs/src/docs/changelog.md) under the **Security** section of the relevant release
- Security advisories in the repository (if supported by the platform)

## Supported Versions

Only the latest version is supported.
We do not fix security vulnerabilities in older versions.
